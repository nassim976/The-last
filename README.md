# THE LAST SIGNAL — NASSIM BOURARA

لعبة بقاء ومغامرة ثلاثية الأبعاد خفيفة تعمل في المتصفح.

## الملفات
- `index.html`: صفحة اللعبة.
- `css/style.css`: الواجهة والتصميم.
- `js/game.js`: عالم Three.js ومنطق اللعب.

## التشغيل من الهاتف
1. ارفع المجلد إلى GitHub كمستودع جديد.
2. فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root).
3. افتح رابط GitHub Pages في Safari أو Chrome.
4. يلزم اتصال بالإنترنت لتحميل مكتبة Three.js من jsDelivr.

يمكن أيضاً فتح `index.html` في محرر/استضافة تدعم تشغيل صفحات HTML مع JavaScript modules. فتح الملف مباشرة من مدير الملفات قد لا يعمل بسبب قيود المتصفح على ES modules.

## التحكم
- عصا اللمس اليسرى: الحركة.
- زر ركض: اضغط باستمرار للركض.
- زر جمع/إرسال: التفاعل مع العناصر وبرج الإرسال.

## المهمة
اجمع 3 قطع إلكترونية، ثم عد إلى برج الإرسال في شمال الجزيرة وأصلح جهاز الاتصال.
تظهر المطاردة بعد جمع أول قطعة. حافظ على صحتك وابتعد عن المخلوق.
